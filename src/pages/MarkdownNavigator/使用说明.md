# Markdown 文档浏览器使用说明
## 1. 功能介绍
本组件用于在前端页面**批量展示、搜索、预览 Markdown 文档**，支持 1000+ 文件稳定加载，无接口依赖、纯静态部署，适合内网文档查阅场景。

- 批量加载 `/public/data/` 下所有 `.md` 文件
- 支持**文档标题模糊搜索**
- 点击列表实时预览 Markdown 内容
- 生产环境稳定、无浏览器请求阻塞问题

---

## 2. 文件目录规范
所有文档必须放在项目固定目录：
```
/public
  /data          # 存放所有 .md 文件（1000个随意放）
  md-manifest.json  # 文档清单（自动生成）
```

---

## 3. 构建清单（必须操作）
### 3.1 生成清单
在本地执行脚本，扫描所有 md 并生成索引文件：
```bash
node scripts/generate-md-manifest.js
```
执行成功后会在 `public/` 生成：`md-manifest.json`

### 3.2 清单格式示例
```json
[
  {
    "name": "使用说明.md",
    "path": "/data/使用说明.md",
    "title": "使用说明"
  }
]
```

---

## 4. 前端 fetch 调用说明
组件只使用两个静态请求，**无后端、无接口、线上直接运行**。

### 4.1 获取文档清单（仅请求1次）
```ts
// 获取全部文档列表
fetch('/md-manifest.json')
  .then(res => res.json())
  .then(data => {
    // 渲染左侧文档列表
    setFileList(data)
  })
```
- 作用：一次性拿到所有 md 的标题、路径、文件名
- 优势：1个请求替代1000个请求，解决浏览器限流、只显示4个文件问题

---

### 4.2 加载单个 Markdown 内容
```ts
// 点击文档时加载内容
const fetchMarkdown = async (item) => {
  const res = await fetch(item.path)
  const text = await res.text()
  const html = marked.parse(text) // 转成网页格式
  setContent(html)
}
```
- `item.path` 格式：`/data/xxx.md`
- 返回：md 原始文本
- 渲染：使用 `marked` 库转为 HTML 展示

---

## 5. 使用流程
1. 将所有 `.md` 文件放入 `/public/data/`
2. 本地执行脚本生成 `md-manifest.json`
3. 将以下文件一起提交上线：
   - `md-manifest.json`
   - `/public/data/*`
   - 前端组件代码
4. 访问页面即可使用：搜索 + 列表 + 预览

---

## 6. 搜索功能说明
- 支持**模糊搜索**：输入任意字符匹配标题
- 大小写不敏感
- 无结果时显示“无匹配结果”
- 纯前端过滤，1000条数据秒级响应

---

## 7. 注意事项
1. **md 文件第一行必须是一级标题**：
   ```markdown
   # 文档标题
   ```
2. 新增/删除/修改文档后，**必须本地重新生成清单并上线**
3. 组件只依赖静态文件，**线上无需执行任何脚本**
4. 1000+ 文件仍可流畅运行

---

## 8. 常见问题
### Q：为什么之前只显示 4 个文档？
A：原代码并发请求 1000 个文件被浏览器限流。本方案使用**构建时清单**，彻底解决。

### Q：线上访问不到文档？
A：请检查：
- `md-manifest.json` 是否部署
- `/data/xxx.md` 是否上传
- 路径是否以 `/data/` 开头
