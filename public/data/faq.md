# 常见问题解答

## Q: 如何重置密码？

A: 管理员可以在后台管理系统中重置用户密码，或通过邮件链接自助找回。

## Q: 登录失败怎么办？

1. 检查用户名密码是否正确
2. 确认账号是否被禁用
3. 清除浏览器缓存后重试
4. 联系管理员确认账户状态

## Q: 数据导入失败？

### 可能原因

- 文件格式不正确（仅支持 Excel/CSV）
- 文件编码问题（请使用 UTF-8）
- 数据量超出限制（单次最多 10000 条）
- 必填字段为空

### 解决方案

```bash
# 检查文件编码
file -i your-file.xlsx

# 转换编码（如需要）
iconv -f GBK -t UTF-8 input.csv > output.csv
```

## Q: 接口请求超时？

- 检查网络连接
- 确认服务器负载状态
- 增加请求超时时间配置
- 联系运维检查服务器状态

## Q: 如何导出数据？

支持以下格式导出：

- Excel (.xlsx)
- CSV (.csv)
- JSON (.json)

> 注意：大量数据导出可能需要较长时间，建议分批处理
